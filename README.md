# 🦾 KUKA KR16 Robot Arm Control

## 🎯 Project Overview
This repository contains the development work for both **low-level** and **high-level control** of the **KUKA KR16 industrial robot arm**. The project bridges embedded systems with robotic motion control, offering hands-on experience in real-time control, communication protocols, and motion planning.
